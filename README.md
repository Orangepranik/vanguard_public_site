# VANGUARD — публічний сайт-каталог

Публічний сайт компанії VANGUARD (Ukrainian Radioelectronic Systems): каталог продукції
для виявлення та протидії БПЛА — детектори, антени, РЕБ-системи, комплекти.

## Структура репозиторію

| Папка | Зміст |
|---|---|
| `site/` | Реалізація сайту — Next.js 16 (TypeScript + Tailwind v4, App Router) |
| `docs/` | Проектна документація: ІА, UX, логіка каталогу, Public DTO, дизайн-система, roadmap |
| `assets/design/` | Вихідні Figma-макети (.fig) — джерело правди для UI |
| `assets/brand/` | Брендові матеріали (логотип) |
| `wireframes/` | HTML-wireframes ранніх ітерацій (v1, v2) |

## Запуск сайту

```bash
cd site
npm install
npm run dev
```

Сайт: http://localhost:3000 (головна тимчасово редіректить на `/catalog`).

## Стан

- ✅ `/catalog` — зверстано за макетом `public_site_catalog_page.fig`: фільтри, сортування,
  перемикач сітка/список, картки продуктів, смуга переваг, футер, мобільне меню (burger + drawer)

  (ERP підключиться пізніше; сповіщення менеджерам — TODO)
- ✅ Контент-шар: `site/src/data/products.json` за схемою Public DTO (демо-дані до переліку продуктів)
- ⏳ Очікуються макети: сторінка продукту, головна, mobile-версії; фото продуктів

## Дані та безпека

Публічний контент будується лише з whitelist-проекції (`site/src/lib/types.ts`);
черга заявок (`.data/`) містить ПІІ і виключена з репозиторію. Деталі — `docs/06-tech.md`.
