## 4. Hero (Y:66, H:209)

Структура: Hero Image → Hero Overlay → Hero Content.

- **Hero Image:** X:0 Y:0 (відносно секції), 1536×209; Fill mode: Fill, позиція
  Center Right; основний об'єкт (машина) — приблизно X:930–1450. Не виносити фото
  в окрему праву колонку.
- **Hero Overlay** (прямокутник 1536×209), лінійний градієнт зліва направо,
  колір `#060A0F`:
  - 0% — 100% непрозорості
  - 35% — 95%
  - 55% — 72%
  - 75% — 15%
  - 100% — 0%
  Додатково можна вертикальний градієнт знизу → `#060A0F` 35%, щоб фото «втопилось»
  у наступну секцію.
- **Breadcrumbs:** X:67, Y:≈84, стиль каталогу: іконка «дім» 14px `#A5A9AD` → «Головна»
  (лінк на `/`) → шеврон 14px `#A5A9AD` → «Рішення»; текст 10/14, gap 8.
- **H1:** X:67, Y:≈127 — «РІШЕННЯ».
- **Опис:** X:67, Y:≈200, W:≈430 — «Комплексні рішення для захисту від безпілотних

## 10. Порядок збирання

1. Фрейм «Desktop / Solutions» + фон.
2. Інстанси з каталожного файлу: Header (active «Рішення»), Advantages, Footer.
3. Hero: фото → overlay-градієнт → крихти → H1 → опис.
4. Заголовок секції + сітка 4×337/18.
5. Один Solution Card → Component → 4 інстанси (міняти лише тексти, теги, зображення,
   іконку) — так картки не «розповзуться» на 5–15 px, як у генерації.
6. Auto Layout: сторінка vertical (gap 0), секції Fixed/Hug; всередині картки фонові
   шари absolute, Content — vertical Auto Layout.
7. Components: Solution Card, Solution Tag, Mini Product Preview, Solution Type Icon
   (+ уже наявні Advantage Item, Footer Column, Footer Link, Social Icon).
