# Поточний стан проєкту

**Оновлено:** 2026-09-01. Цей файл — точка входу для продовження роботи з будь-якої машини.

## Що це за проєкт

Публічний сайт-каталог VANGUARD (Ukrainian Radioelectronic Systems) — виробника засобів
виявлення та протидії БПЛА: детектори, антени, РЕБ-системи, комплекти. Аудиторія:
військові, закупівельники підрозділів, фонди/волонтери, дилери, корпоративні замовники.

## Дизайн

- Джерело правди — `.fig`-файли в `assets/design/` (public_site.fig — перший тест,
  public_site_catalog_page.fig — актуальний каталог). Нові макети розбирати так:
  .fig = zip → `canvas.fig` (kiwi, стиснення **zstd**) → декод пакетами `kiwi-schema` + `fzstd`
  (схема вшита в файл; chunk0 = схема, chunk1 = дані) → дерево вузлів зі стилями/текстами;
  вбудовані зображення лежать у zip у папці `images/`. Розбір автоматизовано — `tools/fig/`
  (`npm run decode -- <canvas.fig> <out>`, пакети kiwi-schema + fzstd): дерево вузлів (JSON) +
  читабельний контур. Уточнення до методу: блок 0 (схема) — raw deflate, блок 1 (дані) — zstd,
  метод визначається за магією байтів; корінь `decodeMessage` викликати **як метод**
  (`compiled.decodeMessage(...)`, інакше губиться `this`). Деталі — `tools/fig/README.md`.
- Токени з макета — у `site/src/app/globals.css` (@theme): фон `#060A0F`, шапка `#000202`,
  картка `#0D1418`, акценти `#E94A02/#E54A02/#D04401`, шрифти Inter + Roboto Condensed (H1/назви).
- Логотипи витягнуті з макета: `site/public/images/brand/` (PNG з прозорістю).

## Ключові рішення власника

- Продажі: **лише заявка** — менеджер зв'язується; онлайн-оплата пізніше.
- Продукти на старті ведуться **програмно** в репозиторії; самописна ERP підключиться
  пізніше через той самий контракт (DTO + черга заявок).
- Ціни публічні («від X грн»), але на картці каталогу ціни немає (макет).
- JS-стек дозволений (Next.js/React), оптимізація продуктивності — окрема пізніша фаза.
- Відгуки/досвід застосування — потрібні, з обов'язковою OPSEC-модерацією (docs/04-logic.md §22).
- **Палітра всіх нових сторінок — канонічні токени каталогу** (`site/src/app/globals.css`,
  джерело — `public_site_catalog_page.fig`); кольори зі згенерованих зображень — лише
  довідка (рішення власника, 2026-08-16).

## Технічні нюанси

- Fixed-оверлеї — **тільки портал** у `document.body` (шапка має backdrop-blur → containing
  block для fixed; на мобільних усередині неї не рендериться текст).
- Посилання списками у футері — `block` (інакше li-strut роздуває рядки).
- Вертикальний ритм сторінки стиснуто під ноутбуки 1366×768 (футер видно без прокрутки).
- Next 16: перед кодом звірятися з `site/node_modules/next/dist/docs/` (див. site/AGENTS.md).

## Docker

Продакшн-образ — Next.js **standalone** (`next.config.ts` → `output: "standalone"`),
`site/Dockerfile` (multi-stage, non-root user) + `docker-compose.yml` у корені. Підняти одним рядком:

```bash
docker compose up --build   # → http://localhost:3000
```

Черга заявок (`/app/.data`, PII) — на іменованому volume `vanguard-requests`, поза образом.
Перевірено: `next build` (standalone) зелений, `server.js` віддає /documentation з HTTP 200
і повним HTML (SSR). Сам образ ще не зібрано — на машині не запущено демон Docker Desktop.
