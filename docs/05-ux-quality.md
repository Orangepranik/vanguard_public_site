# Стандарти якості UX

## 22. Mobile UX

- Один стовпець контенту; сітка карток: 2 колонки від 360 px (компактна картка) або 1 колонка для розширеної.
- **Зона великого пальця:** sticky CTA на сторінці продукту (ціна + заявка), sticky-панель порівняння, кнопка фільтрів — усе внизу екрана.
- **Bottom-sheet замість модалок:** фільтри, форма заявки, майстер підбору.
- Цілі натискання ≥ **44×44 px**; між сусідніми цілями ≥ 8 px.
- Галерея — свайп з індикаторами-крапками; збільшення по кнопці (не обов'язковий pinch).
- Пошук: іконка в шапці → розгортається на всю ширину з автофокусом; клавіатура типу search.
- Телефон і месенджери — живі посилання: `tel:`, `https://t.me/…` (click-to-call з будь-якої сторінки).
- Поля вводу: коректні `inputmode` і `autocomplete` (name, tel); розмір шрифту в полях ≥ 16 px (без авто-зуму iOS).
- Стан користувача (порівняння, список заявки, фільтри, чернетка форми) переживає перезавантаження: localStorage + URL.
- Жодних каруселей з автопрокруткою і жестів без видимої альтернативи-кнопки.

## 23. Desktop UX

- Контейнер 1200–1320 px; сітка 12 колонок.
- Каталог: sidebar фільтрів зліва (sticky, згортані групи), сітка 3–4 колонки.
- Сторінка продукту: галерея зліва (sticky під час прокрутки ТТХ), інформаційний блок справа.
- Hover — лише підсилення (тінь картки, підкреслення); **ніколи не єдиний спосіб** побачити інформацію чи виконати дію.
- Порівняння: до 4 колонок без горизонтального скролу.
- Мегаменю «Каталог»: категорії з однорядковими підписами; «Рішення»: 6 сценаріїв.
- Повна клавіатурна навігація (див. розділ 25); Escape закриває всі оверлеї.

## 24. Стани loading / empty / error / offline

| Секція | loading | empty | error | offline |
|---|---|---|---|---|
| Сітка каталогу | skeleton-картки (6–8) | «Нічого не знайдено» + [Скинути фільтри] + популярні категорії | «Не вдалося завантажити каталог» + [Спробувати ще раз] | показ кешованого + плашка «Немає зв'язку. Показані збережені дані» |
| Пошук | індикатор у полі | zero-result екран (див. 04-logic §17) | локальний індекс — працює без мережі | працює по кешованому індексу |
| Сторінка продукту | skeleton блоків | 404: «Продукт не знайдено» + схожі + в каталог | [Спробувати ще раз] | кешована версія, якщо сторінку вже відвідували |
| Порівняння | skeleton колонок | «Додайте продукти для порівняння» + в каталог | [Спробувати ще раз] | стан у localStorage живий |
| Форма заявки | кнопка з лоадером, поля disabled | — | «Не вдалося надіслати. Ваші дані збережено» + [Ще раз] + телефон | дані збережено; надіслати після появи мережі |
| Відгуки на продукті | — (статичні, запечені в HTML) | «Збираємо відгуки користувачів цього продукту. Користуєтесь ним? Поділіться досвідом» + контакт | медіа не завантажилось → текст лишається, постер-заглушка | текст доступний; відео недоступне з підказкою |

Правила:
- Skeleton замість спінерів для контенту; розміри зображень зарезервовані — **нуль стрибків верстки**.
- Повідомлення про помилки людською мовою; поруч **завжди альтернативна дія** (телефон, месенджер).
- Порожні стани завжди пропонують наступний крок, а не глухий кут.

## 25. Accessibility (ціль — WCAG 2.2 AA)

Аудиторія включає людей після поранень: одна рука, тремор, знижені зір і слух. Це частина основного сценарію, а не «додаткова вимога».

- **Контраст:** звичайний текст ≥ 4.5:1; великий текст та іконки ≥ 3:1. Палітра v1.1 проходить AA (контраст-матриця — [09-design-system.md](09-design-system.md) §4); на акцентних кнопках — темний текст #0B0D0F, білий на помаранчевому ≈3.0:1 не проходить.
- **Масштаб:** база 16 px; збільшення до 200% без втрати функціональності; відносні одиниці.
- **Клавіатура:** повна навігація Tab/Shift+Tab; видимий фокус (outline не прибирається); skip-link «До каталогу».
- **Семантика:** `nav / main / footer`, послідовні h1–h3, списки для сіток, `button` проти `a` за призначенням.
- **ARIA:** акордеони (`aria-expanded`), drawer/bottom-sheet (фокус-пастка, Esc, повернення фокуса на тригер), галерея з підписами, лічильник результатів фільтрів через `aria-live="polite"`.
- **Форми:** видимий label завжди; помилки текстом біля поля + `role="alert"`; помилка ніколи не позначається лише кольором.
- **Статуси наявності:** колір + текст (ніколи лише кольорова крапка).
- **Зображення:** змістовний alt («Детектор КОЖАН, вид спереду, підключені виносні антени»).
- `prefers-reduced-motion` → анімації вимикаються.
- Жодної hover-only функціональності; тач-цілі ≥ 44 px.
- Мова інтерфейсу проста: без канцеляриту і зайвих англіцизмів.

## 26. Performance

> **Рішення власника (2026-08-12):** JS-стек дозволений; бюджети нижче — цільові орієнтири окремої фази оптимізації перед релізом, не блокери розробки.

Бюджети перевіряються в CI (Lighthouse CI, троттлінг Slow 3G, пристрій класу Moto G):

| Метрика | Ціль |
|---|---|
| LCP (каталог, продукт) | ≤ 2.5 с на 4G; ≤ 4 с на Slow 3G |
| INP | ≤ 200 мс |
| CLS | ≤ 0.1 |
| Початковий JS сторінки | ≤ 100 КБ gzip (сума островів) |
| HTML + критичний CSS | ≤ 50 КБ gzip |
| Зображення картки в сітці | ≤ 40 КБ (AVIF/WebP) |
| Повна вага сторінки категорії (перше відвідування) | ≤ 300 КБ |

Техніки:
- **SSG:** весь каталог — статичний HTML з CDN (архітектура — [06-tech.md](06-tech.md) §28). Жодного клієнтського рендерингу контенту.
- Зображення: AVIF/WebP + fallback, `srcset/sizes`, lazy нижче фолда, явні width/height, LQIP-плейсхолдер.
- Шрифти: self-hosted woff2, субсет cyrillic+latin, `font-display: swap`, максимум 2 сім'ї.
- JS лише островами: пошук, фільтри, конфігуратор, порівняння, форма. Без важкого фреймворка в рантаймі.
- Сторонні скрипти: заборонені за замовчуванням; аналітика — self-hosted (див. [08-roadmap.md](08-roadmap.md) §38); жодних чат-віджетів без окремого рішення.
- Кеш: immutable для asset'ів; stale-while-revalidate для JSON каталогу; Service Worker для офлайн-кешу — V2.
- Відео — лише по кліку з постером; **autoplay заборонений**.
