## I. Напрям

### 1. Design philosophy

Сайт — цифровий каталог серйозного інженерного виробника, продукцією якого користуються в реальних умовах. Інтерфейс поводиться як технічна документація гарної верстки: точний, передбачуваний, без жодного елемента «для атмосфери». Продукція — головний візуальний об'єкт; інтерфейс лише допомагає її зрозуміти, підібрати і купити. Технологічність показуємо через якість фотографій, точну сітку, чисту типографіку, реальні характеристики й документи — а не через ефекти. Надійність показуємо через послідовність: однакові картки, однакові кнопки, однакові відступи скрізь. Великий каталог робимо візуально легким через жорстку стандартизацію карток (одна фото-стилістика, 2–4 характеристики, один набір бейджів) і прогресивне розкриття деталей. Мілітарі-косплей виключений: жодного камуфляжу, HUD, неону — стриманість і є ознакою професійності.

### 2. Brand personality

**Інженерний · точний · спокійний · надійний · сучасний.** Голос бренду — фахівець, який поважає час користувача: короткі заголовки («Детектори БПЛА», а не «Наші інноваційні рішення…»), факти замість епітетів, українська без канцеляриту. Емоція виникає з довіри, а не з декору.

### 3. Visual direction

```
темний графіт  +  великі предметні фото  +  один стриманий помаранчевий акцент
+  чітка типографіка (Inter)  +  тонкі 1px-лінії  +  строга сітка  +  контрольований простір
```

Дизайн будується через: композицію, типографіку, фотографію, простір, контраст, сітку.
Дизайн НЕ будується через: glow, градієнти, неон, фонові ефекти, великі тіні (повний список заборон — §53).

## III. Типографіка

### 6. Typography — принципи

- Один основний шрифт для всього інтерфейсу; моно — тільки для технічних значень (SKU, частоти, серійні номери, числа в таблицях). Mono ніколи не для абзаців.
- Максимальна ширина тексту: **65–75 символів** (`max-width: 70ch`). Абзац ніколи не тягнеться на 1440px.
- `font-variant-numeric: tabular-nums` для цін, таблиць і порівняння.
- Формат чисел і одиниць: `1,85 кг` · `12 год` · `4 діапазони` · `45 000 грн` (пробіл-розділювач тисяч; ніколи `45,000.00 UAH`, `1.85kg`).

### 7. Font recommendations

| Роль | Вибір | Альтернативи | Причина |
|---|---|---|---|
| Основний | **Inter** (variable) | Manrope, IBM Plex Sans, Geist | нейтральний, повна кирилиця, широкий діапазон weights, чудова читабельність на малих розмірах |
| Технічний | **IBM Plex Mono** | JetBrains Mono | кирилиця, tabular figures, «інженерний» характер |

Постачання: self-hosted woff2, субсет cyrillic+latin, `font-display: swap`, максимум 2 сім'ї (система вже так вимагає — [05-ux-quality.md](05-ux-quality.md) §26).

## IV. Простір, сітка, форма

### 9. Spacing scale

База 4px: `--space-1…11` = **4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 64 · 80 · 96**. Випадкові значення (17px, 23px, 31px) заборонені без причини.

### 10. Grid

| Пристрій | Колонки | Gutter | Поля контейнера |
|---|---|---|---|
| Desktop (≥1024) | 12 | 24 | 40 (32–48) |
| Tablet (768–1023) | 8 | 20 | 24 |
| Mobile (<768) | 4 | 16 | 16 |

Максимальна ширина сторінки 1440px; контент-контейнер **1280px** (допустимо 1200–1320).

### 11. Containers

`width: min(100% − 2·padding, 1280px); margin-inline: auto;` padding-inline за таблицею §10. Marketing-секції можуть використовувати повну 1440px для фото, текст — завжди в контейнері.

### 12. Border radius

`--radius-sm: 4px` (badge, дрібні елементи) · `--radius-md: 6px` (кнопки, поля, chips) · `--radius-lg: 8px` (картки) · `--radius-xl: 12px` (максимум — великі картки, drawer) · `--radius-pill: 999px` (тільки pill-chips/бейджі). Значення 24/32px — заборонені.

### 13. Borders

Основний спосіб розділення блоків — `1px` межа, не тінь.
Стандарт: `rgba(255,255,255,0.08)` · інтерактивні межі/hover: `rgba(255,255,255,0.16)` · hover карток: `rgba(232,117,36,0.65)` або перехід фону на `--color-surface-elevated`.

### 14. Shadows

Мінімально. Картки не «літають».
`--shadow-sm: 0 4px 16px rgba(0,0,0,0.4)` — dropdown, sticky header (після прокрутки), піднято меню.
`--shadow-md: 0 12px 32px rgba(0,0,0,0.5)` — modal, drawer.
Іншим елементам тіні не призначаються — структуру дають межі й рівні поверхонь.

## V. Елементи керування

### 15. Buttons

Варіанти: **Primary · Secondary · Ghost · Danger · Text · Icon**. Розміри: `sm` h40 (тільки щільні desktop-зони) · `md` h44 · `lg` h48. Radius 6. Padding-inline: 14 / 18 / 24. Font: 15–16 / 600. Мінімальна тач-ціль 44×44 завжди (sm — лише там, де курсор).

| Стан | Primary | Secondary | Ghost |
|---|---|---|---|
| default | bg `#E87524`, text `#0B0D0F` | прозора, border `rgba(255,255,255,.16)`, text `#F0F0F0` | text `#A7AAAD` |
| hover | bg `#F18432` | bg `#1D2227`, border `rgba(255,255,255,.24)` | text `#F0F0F0`, bg `#171B1F` |
| active | bg `#D3661C` | bg `#171B1F` | bg `#171B1F` |
| focus | ring 2px `#E87524`, offset 2px | те саме | те саме |
| disabled | bg `#1D2227`, text `#747A80`, border `rgba(255,255,255,.08)` | text `#747A80`, border `rgba(255,255,255,.08)` | text `#747A80` |
| loading | spinner 16px + текст, `pointer-events:none` | те саме | те саме |

Disabled-токени окремі (`--color-disabled-bg/-text/-border`) — ніколи просто `opacity:.2`. (Контраст disabled-тексту не нормується WCAG — виняток допустимий.)
**Danger:** bg `#B3261E`, text `#FFFFFF`; hover `#C73028`. **Text:** колір accent, underline на hover. **Icon:** 44×44, стилістика ghost, обов'язковий `aria-label`.
Mobile: primary CTA у формах і на сторінці продукту — `width: 100%`.

### 16. Inputs

Висота **48px** (44 у щільних зонах) · padding 12–14 · bg `#171B1F` · border `rgba(255,255,255,.16)` · radius 6 · font 16 (не менше — інакше zoom на iOS) · text `#F0F0F0` · placeholder `#A7AAAD`.

| Стан | Вигляд |
|---|---|
| hover | border `rgba(255,255,255,.24)` |
| focus | border `#E87524` + ring 2px offset 2 |
| filled | як default |
| error | border `#F87171` + повідомлення 13px `#F87171` під полем + текст, не лише колір |
| disabled | bg `#111417`, text `#747A80` |

Label завжди окремо від placeholder (14px/600, зверху); placeholder — лише приклад формату.

**Пошук (§28 брифу):** ключовий компонент — h48, іконка-лупа зліва (20px), плейсхолдер «Пошук за назвою, характеристикою або SKU», кнопка очищення «×» (44px тач-ціль) при непорожньому полі; на mobile розгортається на всю ширину з автофокусом.

### 17. Select

Нативний `<select>` зі стилізацією (колірна схема dark через `color-scheme`) — кастомний компонент лише якщо знадобляться прапорці/пошук усередині, без втрати доступності. Стани: default / open / selected / disabled / error — за таблицею input.

### 18. Checkbox

Контрол 20×20, radius 4, accent-заливка при `checked` (галочка `#0B0D0F`); клікабельна зона ≥44px разом із label (label завжди клікабельний). Використання: мультивибір у фільтрах, згоди.

### 19. Radio

Контрол 20×20; для 2–4 варіантів конфігурації — **radio-chips** (стиль опції конфігуратора: рамка → accent-рамка + `--color-accent-subtle` фон при виборі). Dropdown для 2–4 опцій заборонений.

### 20. Switch

Тільки бінарні налаштування («Лише в наявності»). 44×24, ручка 20, checked = accent. Не для категорій, навігації, вибору з 5 значень.

### 21. Links

Колір accent (#E87524, ≈6.5:1), underline на hover (у суцільному тексті — underline завжди). Ніколи браузерний синій. Відвідані не відрізняємо (каталог, не вікі).

### 22. Badges

Висота 22–24, padding 3–8, radius 4 (pill — лише фільтр-chips), font 12/600.

| Варіант | Фон | Текст |
|---|---|---|
| Neutral | `#1D2227` + border `rgba(255,255,255,.08)` | `#A7AAAD` |
| Success | `rgba(74,222,128,.12)` | `#4ADE80` |
| Warning | `rgba(251,191,36,.12)` | `#FBBF24` |
| Danger | `rgba(248,113,113,.12)` | `#F87171` |
| Info | `rgba(96,165,250,.12)` | `#60A5FA` |
| Accent | `rgba(232,117,36,.14)` | `#F18432` |

**Статуси наявності** (крапка 8px + текст 13–14px; бейдж не є головним елементом картки):
`● В наявності` (success) · `● Виробництво 3–5 днів` (warning) · `● Під замовлення` (warning) · `● Тимчасово недоступний` (danger) · `● Уточнюйте наявність` (neutral).
Бейджами не позначається «кожне друге слово» — максимум 2 бейджі на картці.

## VI. Картки та контент

### 23. Product Card

Анатомія (згори вниз): фото 4:3 → category badge (лише поза сторінкою категорії) → назва (H4 16.5–17/600) → конфігураційний рядок + 2–4 характеристики (14, text-secondary) → статус наявності → ціна (20/700, «від» — 14 secondary) → CTA «Детальніше» (secondary sm).
Параметри: bg `#171B1F`, border `rgba(255,255,255,.08)`, radius 8, padding 12–16, чекбокс порівняння — окрема тач-ціль 44px у куті фото.

**Стани (§35):** default · hover (border `rgba(232,117,36,.65)` + `translateY(-2px)`, 150–200ms — БЕЗ масштабування й тіней) · focused (ring) · selected-for-comparison (border accent 1.5px + позначка) · unavailable (фото opacity .55 + danger-статус; картка лишається клікабельною) · loading (skeleton тих самих пропорцій).

**Фото продукту (§37–38):** aspect 4:3 (1:1 допустимо в щільному каталозі — одне на весь каталог, не впереміш), `object-fit: contain`, внутрішній відступ 8–12px, фон **єдиний для всіх фото** — `#111417`. Виріб чітко відділений від фону; жодних випадкових фонів.

### 24. Category Card

Простіша за продуктову: фото/схема (55–65% висоти) → назва (20–24/600) → пояснення одним рядком (14–16, secondary) → «Переглянути →» (accent, 14–16/500–600, або «N моделей →»).
Фон `#171B1F` (допустимо `#15191D`), border `rgba(255,255,255,.08)`, radius 8. Hover: border `rgba(232,117,36,.65)` або bg `#1D2227`, + `translateY(-2px)` 150–200ms. Без тіней.

### 25. Solution Card

Описує **задачу**, не продукт: іконка/фото сценарію → назва задачі («Для автомобіля») → 1–2 рядки умов застосування → кількість рекомендованих позицій → стрілка. Стилістика Category Card; відрізняється змістом, не оформленням.

### 26. Tables (характеристики)

Структура `Параметр | Значення`: параметр — text-secondary 14; значення — text-primary, технічні числа — mono 13.5 tabular. Розділення: row dividers `1px rgba(255,255,255,.08)` АБО alternating `rgba(255,255,255,0.02)` — одне з двох, не важка сітка з усіма рамками. Рядок ≥40px.
**Mobile (§43):** пара перетворюється на стек «label ↑ / value ↓» (label caption 12 secondary, value 15) або лишається дворядковою, якщо вміщається.

### 27. Tabs

Для сусідніх розділів (Опис · Характеристики · Комплектація · Документація). Активна вкладка: text-primary + underline 2px accent; неактивні — text-secondary. Висота 44–48. Mobile: горизонтальний скрол без обрізання підписів. Клавіатура: стрілки між вкладками, Tab — усередину панелі.

### 28. Accordion

Для ТТХ-груп, комплектації, документації, FAQ — особливо mobile. Summary ≥52px, вага 600, шеврон праворуч (обертання 150ms), border-розділювачі. `aria-expanded`; критичні характеристики не ховаються під акордеон above-the-fold.

## VII. Навігація та оболонка

### 29. Header

Desktop: висота **64–72px** (після прокрутки — 64, sticky). Структура: лого зліва · навігація по центру (Каталог · Рішення · Порівняння · Документація · Про компанію · Контакти) · пошук + CTA «Зв'язатися» справа.
Над hero: фон майже прозорий/`bg-primary`, межа відсутня або ледь помітна — header зливається з hero. Після прокрутки: bg `rgba(11,13,15,.92)` + blur + border-bottom `rgba(255,255,255,.08)` + `--shadow-sm`. Без hide/show-анімацій. Header ніколи не 120px.

### 30. Mobile menu

Header mobile: `[Logo] · · · [Search] [Menu]`, висота 56–60. Menu відкриває drawer (справа або знизу): категорії каталогу → рішення → решта розділів → телефон + месенджери внизу. Пункти ≥48px. Фокус-пастка, Esc/свайп закриває.

### 31. Mega menu

«Каталог» на desktop: колонки категорій з одним рядком пояснення + праворуч 2–3 «Популярні продукти» (мінікартки). Макс-ширина — контейнер; НЕ на весь екран. Відкриття по кліку (не hover-only), закриття Esc/клік поза.

### 32. Breadcrumb

`Головна / Каталог / Детектори / КОЖАН` — 13–14px, text-secondary, розділювач «/», останній елемент text-primary без посилання. На mobile допустимо згортання до `← Детектори`.

## VIII. Оверлеї та стани

### 33. Filters

Desktop: **sidebar** 260–300px, sticky, групи-акордеони (перші дві розгорнуті) — обрано варіант A, бо у детекторів ~7 груп фільтрів. Mobile: кнопка `[Фільтри (2)]` відкриває **bottom sheet** (до 85% висоти) з кнопкою «Показати N моделей».
Активні фільтри — chips над сіткою: `4 діапазони ×` · `Виносні антени ×` + «Скинути всі». Фасетні лічильники; порожні опції — disabled, не приховані. Стан у URL.

### 34. Modal

Тільки для дій, що справді зупиняють флоу. Max-width 560, padding 24, структура header/content/footer, radius 12, bg `#171B1F`, `--shadow-md`, скрим `rgba(4,5,6,.7)`. Esc закриває, фокус-пастка, повернення фокуса на тригер.

### 35. Drawer

Mobile-фільтри, mobile-навігація, швидка форма заявки. Знизу (bottom sheet, radius 12 зверху) або справа 360px. Ті самі a11y-правила, що modal; свайп-вниз закриває bottom sheet.

### 36. Toast

«Заявку надіслано» · «Додано до порівняння» · «Помилка. Спробуйте ще раз». Знизу по центру (mobile) / знизу справа (desktop), 4с, bg `#1D2227`, border, без тіней-гігантів. Критична інформація ніколи не тільки в toast. `role="status"`.

### 37. Tooltip

Затримка 300ms, 13px, bg `#1D2227`, border, radius 4, max-width 260. Тільки додаткова інформація — ніколи єдине джерело змісту (не працює на тачі).

### 38. Loading states

Skeleton (`#171B1F` + пульсація `#1D2227`, 1.2s; вимикається при reduced-motion): ProductCard skeleton, ProductPage skeleton, SearchResult skeleton. Повноекранний спінер для каталогу заборонений. Розміри skeleton = розмірам контенту (нуль CLS).

### 39. Empty states

Ніколи не порожня сторінка. Стандарт: заголовок → пояснення → дія.
«Нічого не знайдено» → «Спробуйте змінити фільтри або пошуковий запит.» → `[Скинути фільтри]` (+ популярні категорії, + «Опишіть задачу — підберемо»).

### 40. Error states

«Не вдалося завантажити дані» + `[Спробувати ще раз]` + альтернатива (телефон). Помилка секції не кладе сторінку: решта лишається робочою. Тексти станів — [05-ux-quality.md](05-ux-quality.md) §24.

## IX. Іконки та рух

### 41. Iconography

Одна бібліотека — **Lucide** (outline, узгоджений stroke). Розміри: 16 / 20 / 24 / 32. Stroke 1.5–2 (стандарт 1.75). Не змішувати з Heroicons/Material/FontAwesome. Іконка без підпису заборонена для важливих дій (замовити, порівняти, завантажити) — виняток лише загальновідомі (лупа, ×) з `aria-label`.

### 42. Motion

Тривалості: `--motion-fast: 120ms` (колір/border) · `--motion-base: 160ms` (hover карток, chips) · `--motion-slow: 240ms` (drawer, modal, акордеон). Easing: `cubic-bezier(0.2, 0, 0, 1)` (ease-out).
Анімуються тільки: `opacity`, `transform`, `border-color`, `background-color`. Layout-анімації заборонені. `prefers-reduced-motion: reduce` → усі переходи ~0ms, пульсація skeleton вимкнена.

### 43. Responsive rules

Breakpoints (Tailwind-стандарт): `sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536`.
Сітка каталогу: ≥1280 — **4 картки** · 1024–1279 — **3** · 640–1023 — **2** · <640 — **1–2** (2 від ~380px при компактній картці).
Два режими щільності (одна система, різний spacing): **Marketing density** (головна, рішення, про компанію — кроки секцій 64–96) і **Catalog density** (каталог, фільтри, порівняння, ТТХ — кроки 16–32, рядки 40–48). Компоненти однакові, змінюються лише відступи.

## X. Макети сторінок

### 44. Product page layout

Desktop above-the-fold: **галерея ≈55% · інформація ≈45%**. Галерея: головне фото 4:3 + thumbnails знизу (64px, активний — accent-межа), sticky при прокрутці ТТХ. Mobile: свайп-галерея з крапками.
Порядок mobile (§67): Breadcrumb → Фото → Назва → Короткий опис → Основні характеристики → Ціна/наявність → CTA → Конфігурація → Детальна інформація (ТТХ-групи, комплектація, сумісність, документи, відгуки, схожі).
Sticky bottom CTA mobile: `45 500 грн · [Замовити]` — 64px, bg `rgba(4,5,6,.94)`, border-top.

### 45. Catalog layout

Breadcrumb → H1 + лічильник → пошук → chips категорій → sidebar фільтрів (desktop) | кнопка фільтрів (mobile) + сортування → активні chips → сітка за §43 → «Показати ще» → sticky-панель порівняння (з'являється при ≥1 обраному).

### 46. Mobile layout rules

Один стовпець; тач-цілі ≥44; primary CTA full-width у формах; bottom-sheet замість модалок; sticky CTA на продукті; заборонено hover-only. Повний перелік — [05-ux-quality.md](05-ux-quality.md) §22.

### 47. Documentation UI

Картка файлу: іконка PDF (20) → назва (15/600) → `PDF · 2,4 МБ` (13, secondary — розмір обов'язково: слабка мережа) → дії `Переглянути` / `Завантажити` (text-links accent). Рядок ≥56px, у списку — border-розділювачі. Блок «Документація» на головній — картки простіші за продуктові + `[Перейти до документації]`.

### 48. Review / case UI

Картка відгуку: `фото/відео | текст` (desktop) або стек (mobile); border-left 3px accent; підпис — 13px secondary: **позивний або роль** («Оператор РЕБ», «Боєць підрозділу Сил оборони»), контекст застосування, місяць публікації, позначка «перевірений відгук ✓».
**Без фальшивих рейтингів:** зірки/«5.0»/«100% рекомендують» заборонені, поки немає реальної рейтингової системи. Відгук виглядає як підтвердження експлуатації, не як ecommerce-review.
Медіа проходить OPSEC-чекліст ([04-logic.md](04-logic.md) §22): обличчя, номерні знаки й борти техніки, координати/гео, позиції, позивні (без згоди), номери підрозділів, екрани обладнання (налаштування/частоти), метадані файлів. Джерело завжди можна знеособити.

## XI. Якість

### 49. Accessibility

Обов'язково: повна клавіатурна навігація · видимий фокус (ring 2px accent, offset 2) · семантичний HTML (nav/main/список для сіток, button vs a) · ARIA лише де потрібно (акордеон, drawer, live-лічильники) · контраст за матрицею §4 · доступні форми (label, помилки текстом, `role="alert"`) · alt-тексти змістовні · reduced motion · тач-цілі ≥44. Повні вимоги — [05-ux-quality.md](05-ux-quality.md) §25.

### 50. Performance constraints

Дизайн не має права вимагати важких ефектів. Заборонено/обмежено: background video, WebGL, parallax, великі GIF, нестиснуті PNG. Зображення: AVIF → WebP → fallback JPEG; responsive `srcset/sizes`; lazy нижче першого екрана; явні розміри. Бюджети — [05-ux-quality.md](05-ux-quality.md) §26 (вони первинні для будь-якого дизайн-рішення).

### 53. Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| Межі 1px і рівні поверхонь для структури | Великі тіні, «літаючі» картки |
| Один акцент ≈5–10% площі | Помаранчевий фон півсторінки |
| Темний текст `#0B0D0F` на акцентних кнопках | Білий текст на акценті (3.0:1 — провал) |
| Фото на єдиному фоні `#111417` | Випадкові фони фото в каталозі |
| «Детектори БПЛА» | «Наші інноваційні технологічні рішення для сучасних викликів» |
| `45 000 грн`, `1,85 кг`, `12 год` | `45,000.00 UAH`, `1.85kg`, `12hrs` |
| ● колір + текст статусу | Тільки кольорова крапка |
| Радіо-chips для 2–4 опцій | Dropdown для 2 опцій |
| Скелетони в розмір контенту | Fullscreen-спінер каталогу |
| Реальні відгуки з позначкою перевірки | ★★★★★ 5.0 без рейтингової системи |
| Тонка технічна графіка у hero (3–8% opacity) | Радар/приціл/HUD, камуфляж-фон, неон, glassmorphism, parallax, 3D-обертання, autoplay-відео |

Premium створюють (§80, §118): якісна предметна фотографія · великі контрольовані поля · строга сітка · сильна типографічна ієрархія · мінімум кольорів · точні відступи · акуратні межі · послідовність компонентів · реальні технічні дані й досвід використання.

```
ЧОМУ НАМ ДОВІРЯЮТЬ · 4 причини: Технічні характеристики · Документація ·
  Реальні фото та відео · Відгуки користувачів (іконка Lucide 20–32/1.75 + заголовок + 1–2 рядки)
ДОСВІД ВИКОРИСТАННЯ · картки [фото/відео | відгук + роль + продукт] · без зірок
ДОКУМЕНТАЦІЯ · 3 прості картки (Інструкції · Паспорти · Сертифікати) + [Перейти до документації]
CTA · «Потрібна допомога з вибором?» + [Отримати консультацію] [Оформити запит]
  (фонове фото допустиме — сильно затемнене, контраст тексту зберігається)
FOOTER · лого + опис зліва · колонки навігації · контакти справа · legal
```
