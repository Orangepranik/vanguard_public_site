# VANGUARD public site — інструкції для Claude Code

Перед будь-якою роботою прочитай **docs/10-project-state.md** — там повний поточний стан
проєкту, ухвалені рішення і наступні кроки.

## Ключові правила

- Мова сайту, документації та комунікації — **українська**.
- Джерело правди для UI — **Figma-макети власника** в `assets/design/*.fig` (не вигадувати
  дизайн; чого нема в макеті — робити в його мові й позначати як пропозицію).
- Публічні дані — лише через whitelist-типи `site/src/lib/types.ts` (Public DTO);
  нічого поза ними назовні не віддавати.
- `site/.data/` (черга заявок) містить персональні дані — **ніколи не комітити**.
- Fixed-оверлеї (модалки, drawer'и) — тільки через React-портал у `document.body`:
  шапка має `backdrop-filter`, всередині неї fixed-елементи рендеряться глючно на мобільних.
- Продажі — лише через заявку (`POST /api/requests`), без кошика й оплати (рішення власника).
- Проєктна документація UX/архітектури — у `docs/` (01–09); при суперечності з .fig-макетом
  пріоритет за макетом.

## Запуск

```bash
cd site && npm install && npm run dev
```
