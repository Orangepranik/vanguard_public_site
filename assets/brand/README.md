# Брендові матеріали VANGUARD

Сюди складаються вихідні файли логотипа та фірмових матеріалів.
Назву **VANGUARD** і палітру затверджено 2026-08-12 (див. [docs/06-tech.md](../../docs/06-tech.md), розділ 32).

## Потрібні файли від власника

| Файл | Що це | Формат |
|---|---|---|
| `logo-full.svg` | Повний лок-ап: монограма + VANGUARD + тагл + крила зі щитом | SVG (або PNG з прозорим фоном, ≥ 1500 px) |
| `logo-horizontal.svg` | Монограма + VANGUARD в один рядок (для шапки) | SVG або PNG прозорий |
| `logo-mark.svg` | Сама монограма з трикутників (фавікон, дрібні розміри) | SVG |
| `logo-*-light.svg` | Світла монохромна версія (#F0F0F0) для темного фону | SVG |

Якщо є лише один растровий файл (як надісланий у чаті) — покладіть його сюди як
`logo-original.png`: світлу монохромну та SVG-версії підготуємо на етапі UI-системи.

## Стартові правила використання

- Фон сайту темний (#0B0D0E) → логотип завжди у світлому виконанні.
- У дрібних розмірах (шапка, фавікон) — чистий монохром без металевого градієнта.
- Мінімальні розміри та охоронне поле зафіксуємо після отримання вихідників.
